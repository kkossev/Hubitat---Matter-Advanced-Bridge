# Matter Advanced Bridge

A Hubitat Elevation driver package for Matter bridges. The parent driver discovers the devices behind
a Matter bridge, creates one Hubitat child device per endpoint, subscribes to the supported Matter
attributes and events, and routes reports to the children.

Supported bridges include Zemismart M1, Aqara M3 and E1, SwitchBot Hub 2, IKEA DIRIGERA, Philips Hue,
and the Home Assistant Matter bridge.
