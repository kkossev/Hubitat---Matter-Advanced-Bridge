Matter Advanced Bridge driver supports the following device types 
* Switches
* Dimmers
* Color Temperature bulbs
* RGBW bulbs
* Contact sensors
* Illuminance sensors
* Temperature sensors
* Humidity sensors
* Motion (occupancy) sensors
* [Window Covering devices](../drivers/window-shade.md)
* Locks (status only!)
* Battery reportings
