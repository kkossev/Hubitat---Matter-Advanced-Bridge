# Support and links

Applies to: 1.9.0 | Last verified: 2026-07-27 | Status: Current

## Getting help

**[Matter Advanced Bridge release thread](https://community.hubitat.com/t/release-matter-advanced-bridge-limited-device-support/135252)**
— the support thread for the released package, and the link behind the **Community Link** button on
the device page. Post here for help.

Before posting, see [asking for help](troubleshooting.md#asking-for-help) for the information worth
including, and check [Known issues](known-issues.md).

**[The original project thread](https://community.hubitat.com/t/project-zemismart-m1-matter-bridge-for-tuya-zigbee-devices-matter/127009)**
— where the project started, and still the link recorded in the package manifest. It holds a lot of
development history and early device reports.

## The project

- **Source code and releases:** <https://github.com/kkossev/Hubitat---Matter-Advanced-Bridge>
- **Report a bug or request a device:** the community thread above is read more often than the
  GitHub issue tracker.
- **Wiki:** <https://github.com/kkossev/Hubitat---Matter-Advanced-Bridge/wiki> — the documentation
  you are reading is replacing it. It is still the authoritative source until that migration
  finishes.

## Installation

- **Hubitat Package Manager:** <https://hubitatpackagemanager.hubitatcommunity.com/> — the
